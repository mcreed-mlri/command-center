Team board

Using the Command Center

Open trainingunit.pages.dev. Everything on the board opens in a new tab except Focus Pages, which stay in the same tab.

What’s on the board

  • Planning & Collaboration — Google Drive folders (project tree) and Monday.com workspaces/boards
  • LMS — Learning Hub, Brightspace Manager, Brightspace (D2L), D2L Academy
  • Important Documents — LACE Project Planning, Meeting Notes, Weekly Meeting Agenda, Faculty Database, Curriculum Map
  • Quick Links — Slack, Otter.ai, Claude

Day-to-day moves

  1. Find a Drive folder or Monday board. Expand Google Drive or Monday.com, then drill into the project you need. Nested folders have an “Open whole folder” option.
  2. Jump to a standing doc or app. Use Important Documents or Quick Links when you already know the destination.
  3. Search when you don’t remember where something lives. Press / or click the magnifying glass. Type a word — the board filters live.
  4. Open your Focus Page. Click your letter avatar (A / C / O / M) in the top right.
  5. Optional: Use the theme toggle for light or dark. Your choice is saved for next time.

Gray tiles marked “soon” are not ready yet — they won’t open. If a link is missing or outdated, contact Marlie (footer of the page).

Personal

Using your Focus Page

Your Focus Page is for your Monday work and personal shortcuts. Open it from the avatar stack on the Command Center, or bookmark your URL (e.g. …/marlie/).

Monday milestones

  • Tasks pull from the six LACE boards: Operations, LMS, Content Design, Data & Evaluation, Comms & Branding, and Sustainability Roadmap.
  • A snapshot refreshes overnight. Hit Refresh anytime you want a live pull from Monday.
  • Click a task to open that item in Monday.
  • Use the Filter button (left side of the toolbar) to narrow by status or area. Active filters show next to the button label (e.g. Filter · Waiting).
  • Switch views with the Week · List · Board · Calendar pills on the right — all four options are always visible:
  • Week — this week by day (default)
  • List — Overdue, Due soon, Coming up, Later, No due date
  • Board — kanban by status
  • Calendar — month grid
Working on it Waiting Overdue Done (when shown)

My Pins

Personal bookmarks that sync across your devices when you’re online. Click Manage to add, edit, reorder, or delete pins. Use them for the links you open constantly that don’t belong on the shared board.

My List

A private scratch list — add items, check them off, reorder, and clear finished ones. Handy for small reminders that aren’t Monday tasks.

Privacy note: Focus Pages don’t require a login. Anyone on the team who has the URL can open any page. Treat them as personal workspaces, not secret vaults. Pins and lists sync for your page across your browsers/devices.

Install

Install as an app

The Command Center is a progressive web app (PWA). Installing it puts a Training Unit icon on your desktop, taskbar, or home screen and opens it in its own window — no browser tabs cluttering the view.

Tip: Install from the main Command Center URL first (trainingunit.pages.dev). You can still open Focus Pages from the avatar stack inside the app. If install isn’t offered, pin the tab instead — that works fine too.

Windows Chrome or Edge

Best experience for daily laptop use

  1. Open https://trainingunit.pages.dev in Chrome or Microsoft Edge.
  2. Look in the address bar for an install icon (computer with a down arrow) or an Install / App available prompt.
  3. Or open the browser menu (⋯) → Install Training Unit — Command Center / Apps → Install this site as an app.
  4. Confirm. An app window opens, and you can pin it to the taskbar or Start menu.
  5. Launch it from the taskbar/Start like any other app. It opens without the browser chrome.

Mac Chrome, Edge, or Safari

Desktop app window from the Dock

  1. Open https://trainingunit.pages.dev.
  2. Chrome / Edge: Click the install icon in the address bar, or menu → Install Training Unit — Command Center.
  3. Safari (macOS Sonoma+): File → Add to Dock (wording may be “Add to Dock…”).
  4. Open the app from the Dock whenever you need it.

iPhone or iPad Safari

Add to Home Screen — required browser is Safari

  1. Open https://trainingunit.pages.dev in Safari (not Chrome or Firefox on iOS for this step).
  2. Tap the Share button (square with an up arrow).
  3. Scroll and tap Add to Home Screen.
  4. Name it something short like “Training Unit,” then tap Add.
  5. Open it from your home screen. It launches full-screen like an app.

Android phone Chrome

Install prompt or menu install

  1. Open https://trainingunit.pages.dev in Chrome.
  2. If you see an Install app banner, tap it.
  3. Otherwise tap the menu (⋮) → Install app or Add to Home screen.
  4. Confirm. Open the Training Unit icon from your home screen or app drawer.

If you prefer not to install

  • Pin the tab in Chrome/Edge (right-click the tab → Pin).
  • Or bookmark the Command Center and your Focus Page in a bookmarks bar folder.

Once

Quick start checklist

Do this once, then you’re set for daily use.

  • Open https://trainingunit.pages.dev and confirm you can reach Drive, Monday, and docs
  • Press / and try searching for “LACE” or “Slack”
  • Click your letter avatar and open your Focus Page
  • Scan this week’s milestones; hit Refresh if the snapshot looks stale
  • Add 2–3 personal links under My Pins (Manage → Add a pin)
  • Install the site as an app on your main computer (and phone if you want)
  • Pin the app or tab so it’s always one click away
